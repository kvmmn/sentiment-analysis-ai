# Saintiment keyword systems — host evaluation

Date: 2026-08-31 (Europe/Berlin)
Status: academic evaluation of a sourced keyword pack. Not a collection licence. Not frozen query version 1 (no live database counts).
Object: sentiment about GenAI and deskilling in architectural discourse (profession, studio, education), with soft/hard skills and stakeholder differences.

Decisions accepted:
1. Three instruments, never mixed: (a) literature retrieval (Scopus/WoS/IEEE/Scholar); (b) discourse-retrieval catalog; (c) sentiment/stance coding lexicon. Using excited/hype/threat as search terms is query bias, not measurement (Grimmer, Roberts and Stewart 2022 ch.4; Loughran and McDonald 2011; van Atteveldt et al. 2021).
2. Two layers. Layer A = architecture AND GenAI. Layer B = skill/deskilling as a second filter.
3. Construction/AEC/built environment/sociotechnical-lifecycle strings stay related-work.
4. Do not cite 71 opinions / 6173 words as a published fact until a PDF is in hand. Exact dual match NOT identified in open full text (2026-08-31).
5. Verified LinkedIn n: Ghimire, Kim and Acharya (2024), Buildings 14(1):220, https://doi.org/10.3390/buildings14010220 — 32 opinions / 63,778 words.
6. Closest object+sentiment paper, methods unread: Larbi et al. (2026), TFSC 228:124689, https://doi.org/10.1016/j.techfore.2026.124689. Circumstantial 76% of 71 is not evidence.
7. Primary literature string is S-A1 / W-A1. No LIMIT-TO Engineering. No deskilling in A. Live counts not run.
8. Persian/German lists are separate. Explicit GAPs: ISO 6707 FA/DE; UNESCO FA; Farhangestan replacement for hush-e masnui (hushvare/humas not approved); maharat-zedayi not architecture-journal jargon; no official FA/DE hashtag sets; do not invent archviz calques.
9. Existing keyword-lexicon.md (2026-08-29) remains the English discourse core.
10. Query version 1 is not frozen.

When writing FA terms use Persian script with transliteration: معمار (me'mar); معماری; مهندس معمار; رشته معمار; هوش مصنوعی مولد (preferred GenAI lemma); پرامپت‌نویسی; نویسندگی; تفکر نقادانه; استودیو. Do not invent further FA lemmas.

Do not freeze query v1. Do not authorise collection. If any URL/DOI is uncertain, mark TODO rather than guess.
